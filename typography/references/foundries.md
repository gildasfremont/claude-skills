# Fonderies indépendantes — Référence rapide

Qui fait quoi, et leurs polices qui comptent. Classé par pertinence (les plus utiles en premier).

---

## Tier 1 — Fonderies de référence (les incontournables)

### Klim Type Foundry — klim.co.nz (NZ, Kris Sowersby)
Le meilleur rapport culture/qualité/utilité. Chaque police est ancrée dans l'histoire typo mais dessinée pour aujourd'hui.
- **Söhne** — Le remplaçant d'Helvetica. Versions Breit (large), Schmal (étroite), Mono. Standard Stripe, Linear.
- **Tiempos** — Serif transitionnelle contemporaine. Text + Display. Standard journalisme/éditorial de qualité.
- **Founders Grotesk** — Grotesque avec du caractère. Le bon choix quand Helvetica est trop neutre et Neue Montreal trop jeune.
- **Calibre** — Géométrique précise. Tech, clean.
- **Domaine** — Serif display luxe. Haut contraste, mode, éditorial haut de gamme.
Prix : ~150-200€ par famille desktop. Web en plus.

### Grilli Type — grillitype.com (Suisse)
Heritage Swiss Design, exécution irréprochable, familles très larges.
- **GT Walsheim** — Géométrique chaleureuse. La géométrique qui ne fait pas froid. 8 graisses + condensed.
- **GT America** — Synthèse grotesque US/EU, 84 styles. La police corporate contemporaine de référence.
- **GT Sectra** — Serif contemporaine, contrastes aiguisés. Éditorial intellectuel.
- **GT Flexa** — Variable, expérimentale, adaptive.
Prix : ~150-250€ par famille.

### Dinamo — abcdinamo.com (Berlin)
Pricing basé sur la taille de l'organisation (indie → enterprise). Très présent dans la culture, la tech, les institutions.
- **ABC Diatype** — Géométrique distinctive, bonne en UI. + version Mono.
- **ABC Favorit** — Grotesque géométrique. Tech-culture.
- **ABC Monument Grotesk** — Brutaliste, display. Institutions culturelles.
- **ABC Arizona** — Serif dramatique, éditorial haut de gamme.
- **ABC Whyte** — Neo-grotesque + variante Inktrap pour le print.
Prix : variable selon organisation.

### Commercial Type — commercialtype.com (NY/Londres, Paul Barnes + Christian Schwartz)
Custom pour The Guardian, NYT, Esquire. Catalogue retail excellent.
- **Graphik** — La sans-serif polyvalente de référence. UI, branding, partout.
- **Guardian Egyptian** — Slab serif, journalisme.
- **Atlas Grotesk** — Neo-grotesque contemporaine, corporate.
- **Dala Floda** — Display serif audacieuse.
Prix : ~150-250€ par famille.

## Tier 2 — Fonderies de qualité (choix distinctifs)

### Pangram Pangram — pangrampangram.com (Montréal)
Modèle free-to-try. Bon rapport qualité/prix. Catalogue large.
- **Neue Montreal** — LA grotesque cool. Inspirée Expo 67. 14 graisses + Mono.
- **Editorial New** — Serif élégante. Luxe accessible.
- **Agrandir** — Display sans, énergie.
- **Migra** — Serif variable expressive.
Prix : ~50-100€ par famille en licence commerciale.

### Sharp Type — sharptype.co (NY)
- **Sharp Grotesk** — Très large famille, Frutiger-inspirée. Systèmes complexes.
- **Sharp Sans** — Campagne Clinton 2016, Dropbox.
Prix : ~150-200€.

### Lineto — lineto.com (Suisse, pionnière)
- **Circular** — LA géométrique startup/tech. Spotify, Airbnb l'utilisent.
- **Akkurat** — Neo-grotesque précise. Institutionnel.
- **LL Brown** — Géométrique plus chaleureuse que Futura.
Prix : ~200-300€.

### OH no Type Co — ohnotype.co (James Edmondson)
"Organique plutôt que géométrique." Fun, vivant.
- **Degular** — Sans display chaleureuse.
- **Ohno Blazeface** — Display expressive, audace.
- **Vulf Sans/Mono** — Rétro-groove.
Prix : ~30-60€ par famille.

### Colophon Foundry — colophon-foundry.org (Londres/LA, acquise par Monotype 2023)
- **Aperçu** — Géo-grotesque culte. Beaucoup copiée.
- **Space Mono** — Monospace avec personnalité (aussi sur Google Fonts).
Prix : ~100-200€.

### Milieu Grotesque — milieugrotesk.com (Suisse)
Catalogue restreint mais pointu.
- **Maison Neue** — Neo-grotesque premium. Branding mode.
Prix : ~200€.

## Tier 3 — Fonderies spécialisées / open source

### Production Type — productiontype.com (Paris, Jean-Baptiste Levée)
Custom luxe/industrie. Héritage A.M. Cassandre.
- **Spectral** — Serif Google Fonts, bonne qualité gratuite.

### Velvetyne Type Foundry — velvetyne.fr (France, collectif open source)
Tout est gratuit. Polices expérimentales, souvent excellentes pour des projets culturels.
- **Pilowlava**, **Avara**, **Compagnon**, **Sligoil**

### Atipo — atipofoundry.com (Espagne)
Fonderie généreuse, beaucoup de free fonts.
- **Bariol** — Rounded accessible.

### Typotheque — typotheque.com (Pays-Bas)
Spécialiste multilingue/multi-scripts.
- **Fedra** — Famille étendue (sans, serif, mono).

### Future Fonts — futurefonts.xyz
Plateforme de polices en développement. Achat anticipé, prix réduit. Lieu de découverte.

### ANRT — anrt-nancy.fr (France)
Formation et recherche. Polices expérimentales de haute qualité.
